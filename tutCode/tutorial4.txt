Define:

State - 
The situation which th agent can find itself in

Search tree - 
a tree where the root node is the start state and the set of children
for each node consists of the states reachable by taking any action

Action - 
Something in which an agent can choose to do

Transition model - 
a graph whos nodes are the set of all states, and whose links are actions that transform one state to another

Branching factor - 
number of available actions to the agent

Describe what we mean by abstraction in problem solving:
Unnecessary details are removed in order to have an abstract representation of the problem.
